钱上门了，他挑三拣四

嗐，11 月 17 日，DeepSeek 的工商信息变了。新增一家合伙企业。数字不大，动静不小。

这是一轮 1050 亿的融资，落定了。31 家合伙人，腾讯 3.29 亿，宁德时代 3.29 亿，两个并列最多。

创投圈的规矩，历来是投资人挑项目。这回反过来了，是项目挑投资人。机构挤破头抢份额，还要过三道关。

梁文锋发表演讲，资料图

三道关，一道是穿透审查，底层名单全上报；二道是锁定期七年，上市后再加五年；三道是不合规的 LP，改不好，份额直接收回。

有人拿着钱，被拒之门外。有人拿到份额，自己放弃了。梁文锋不缺钱。首轮 510 亿，他自己掏了 200 亿。

他攥着约 89.5% 的股份，表决权几乎 100%。钱可以进来，权不能动。这不叫融资，这叫挑队友。

挑的，是能不能一起熬七年。梁文锋要的，是能陪他熬到 AGI 的人……

用户在用，他往外赶

同一周，另一件事更反常。11 月 15 日下午，不少用户发现，超过 72 小时的长对话，续不上了。

App 弹了一条提示，算力不足，暂不可用，导出对话，到其他 App 用。

别人家的免费额度用完，弹出来的是开会员按钮。DeepSeek 弹出来的，是请你出门左转。这事有前兆。

11 月 13 日，DeepSeek 开放了全家桶应用 API。联网搜索、深度思考、文件输入、阅读链接、语音，全做成了接口。还开源了一个聊天前端，填上 API Key 能用。

官方放话，自己动手，能一比一复刻一个 DeepSeek App。先给你出口，再设上限。顺序反了，意思正了。

聊天框，梁文锋早讲过，算不上主业。大家抢 C 端流量，他盯着 AGI 路线图。模型先让自己好用，下一版做得更快。

崔添翼打了个比方，聊天框像手机自带的闹铃和计算器。手机自带一个，够用行，外面有更好的，用别人的。

DeepSeek 的月活约 1.3 亿。1.3 亿人用的产品，在他嘴里只是个基础形态。这话够狂，也够实在。

算力是瓶颈，也是答案

提示里写的原因，是算力不足。梁文锋自己也认，阻止 Scaling 的，是算力。中美 AI 的差距，他归结为一件事，算力资源的区别，国产算力硬件没问题，唯一的问题是产能不够。这话他讲过不止一次，算力是头号难题。

算力不够，怎么办？梁文锋把力气花在刀刃上。研究排在最前头，C 端和 B 端都是副产物。DSH 是副产物里长得最快的一个。

DeepSeek 公司前台，资料图

截至 11 月 4 日，DSH 里用 DeepSeek 官方 API 的用户，日活 154 万。每天要消耗 92 万亿 token。社区插件有 3.5 万个，约 60% 的活跃用户，装过至少一个插件。

DSH 8 月 13 日上线，桌面版 9 月 29 日发布。刚出来的那一周，日活 27.1 万。不到两个月，翻了五倍多。

DSH 中间是一套叫 Cordis 的插件机制。出厂自带的 53 个工具，全是插件。

先有安装，再补审核，顺序是反的（你没看错）。社区里出过一个破甲插件，作者闭源删库，镜像早散出去了。DSH 时刻，比 App Store 时刻，更有冲击力。

普通人能带走什么

你可能要问，这跟我有什么关系？关系有三条。头一条，你的 DeepSeek 长对话，超过 72 小时，续不上了。别慌，导出对话，能接着用。

手机上的 DeepSeek 应用，资料图

想自己搭一个，官方 chat-demo 开源，填上 API Key 能跑。下一条，免费的东西，正在变贵。算力是硬约束，额度管理会收得更紧。

学会用 API 和插件，别只盯着聊天框。DSH 这种 Agent 产品，是梁文锋真正下注的地方。1.3 亿人里，60% 的人已经装过插件。你装过吗？没装过，现在装，还不晚。

钱要挑，人要挑，用户也要挑。挑来挑去，挑的是一个能长久的东西。

梁文锋反着来，是因为他算过账。DeepSeek 的故事还没写完，下一章，大概还是反着来。
